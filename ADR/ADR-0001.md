# ADR-0001: Control Plane Design

**Status:** Accepted  
**Date:** 2026-03-03  
**Authors:** Maya (Platform Architect)

---

## Context

The 9TEVE-OS stack involves multiple autonomous agents (SWE-AF, OpenHands), workflow engines (n8n, Prefect), memory systems (Mem0), governance tooling, and secrets management (Vault). Without a unified control plane, each component would need its own identity, policy, and audit mechanisms — leading to fragmentation and security gaps.

## Decision

We will implement a **single Control Plane** that acts as the central authority for:

1. **Run lifecycle** — create, monitor, cancel, approve gated steps
2. **Task scheduling** — create tasks, dispatch to agent runners (with policy gate)
3. **Policy enforcement** — evaluate action envelopes before any side effect
4. **Artefact management** — store immutable, content-addressed outputs
5. **Telemetry** — emit structured log events with `trace_id`, `run_id`, `tenant_id`

The Control Plane API is versioned under `/v1` and documented via `specs/control-plane.openapi.yaml`.

## Core Contracts (Non-Negotiables)

1. Every tool/agent call is wrapped in an **Action Envelope** (see `specs/action-envelope.json`).
2. Side-effect actions (`GIT_PUSH`, `DEPLOY`, `SECRET_ACCESS`, `OUTBOUND_NETWORK`, `PUBLISH_DOCS`) require a policy gate before execution.
3. Every run produces an **audit pack** (plan, diffs, test results, policy decisions) stored as immutable artefacts.

## Consequences

- **Positive**: Single point of governance; consistent audit trail; policy can be upgraded independently of agents.
- **Negative**: Control Plane is a potential single point of failure; requires careful SRE attention (see ADR-0003).
- **Mitigation**: Policy PDP failure defaults to *deny*; Vault unavailability degrades to "no-secrets" mode.

## Alternatives Considered

- **Distributed policy enforcement** (each agent checks its own policy): Rejected — inconsistent enforcement, harder to audit.
- **No control plane** (direct agent invocation): Rejected — no audit trail, no identity, no policy gates.
